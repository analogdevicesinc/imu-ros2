\doxysubsection{Detailed Description}
Exponentially Weighted Moving Average covariance estimator. 

Computes variance using exponential smoothing\+: variance\+\_\+t = alpha \texorpdfstring{$\ast$}{*} (x\+\_\+t -\/ mean\+\_\+t)\texorpdfstring{$^\wedge$}{\string^}2 + (1-\/alpha) \texorpdfstring{$\ast$}{*} variance\+\_\+\{t-\/1\}

Adapts continuously with O(1) memory. Alpha controls responsiveness\+:
\begin{DoxyItemize}
\item Higher alpha (0.\+1)\+: Fast adaptation, more sensitivity
\item Lower alpha (0.\+01)\+: Slow adaptation, smoother estimates 
\end{DoxyItemize}
